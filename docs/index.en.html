02 / Web and desktop applicationPersonal project · Beta

Mappleo

Your job search, connected. Even when you are offline.

An application that brings companies, job offers, applications, contacts and networking together, with a Kanban board, calendar and statistics. Available on the web and as a Windows application.

MY ROLE

Personal project · Design, full-stack development and desktop application

OUTCOME

Functional beta with a deployed web app, Windows installer, offline use, optional synchronisation and an interactive web demo without registration.

View demo (opens in a new tab)GitHub (opens in a new tab)Download for Windows (opens in a new tab)

The problem

Keeping a job search from becoming scattered across spreadsheets, notes and emails, with no clear record of applications or next steps.

What I did

I designed and developed the complete product: data model, responsive interface, API, authentication, application tracking, board and statistics. I extended it to Windows with local storage and optional synchronisation.

What I learned

Designing one product for browser and desktop, sharing business rules and resolving synchronisation between local and remote data while preserving offline work and file privacy.

Development decisions and details

Work offline

Electron and encrypted local SQLite storage allow the app to work without Internet access. Linking a web account is optional; changes sync when connectivity returns, and conflicts requiring a decision are presented to the user.

Separate records from files

Shared rules and validation across web and desktop. CVs and cover letters stay exclusively on the computer, with previews and links to job offers, without being uploaded to the web.

Protect and test

Server-side permissions and validation, password hashing, personal-field encryption and tests with Vitest and Playwright. Docker for local development, GitHub Actions for CI and a public demo independent of production services.

Web screenshots use the fictional John Miller profile and are in Spanish. The static demo lets visitors try workflows with temporary changes in the browser; it does not connect to real accounts. The beta Windows installer is not digitally signed yet.
