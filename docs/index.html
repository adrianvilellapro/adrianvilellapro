01 / Extensión de navegadorTFG · 10/10

Nutrivisor

Información nutricional integrada directamente en la compra online.

Una extensión de Chrome que amplía la tienda online de Mercadona con datos de Open Food Facts: indicadores, filtros y avisos durante la compra.

MI PAPEL

Proyecto individual · Diseño, investigación y desarrollo

RESULTADO

Trabajo de Fin de Grado calificado con 10/10 y extensión publicada en Chrome Web Store.

Chrome Web Store (se abre en una pestaña nueva)GitHub (se abre en una pestaña nueva)

El problema

¿Cómo mostrar información nutricional útil sin obligar al usuario a abandonar la tienda en la que está comprando?

Qué hice

Investigué cómo identificar los productos, conectar fuentes externas e integrar la información en una web sobre la que no tenía control.

Qué aprendí

Trabajar con datos externos que no siempre llegan completos, diseñar soluciones tolerantes a errores y transformar información compleja en algo útil.

Decisiones y detalles del desarrollo

Conectar los datos

Identificación de productos e integración con Open Food Facts, contemplando información incompleta.

Hacerlos útiles

Nutri-Score, NOVA, alérgenos, aditivos y filtros consultables en la propia tienda.

Integrarlos en la compra

Extensión Chrome Manifest V3 y caché en local storage para reutilizar la información consultada.

TECNOLOGÍAS
  • JavaScript
  • Vite
  • Chrome Extensions
  • APIs
  • Open Food Facts
  • Web Augmentation
02 / Aplicación full stackProyecto personal

WikiCodex

Organizar información compleja. Decidir quién puede verla.

Una plataforma para gestionar campañas de rol, personajes, lugares, objetos y contenido narrativo dentro de wikis privadas.

MI PAPEL

Proyecto personal · Desarrollo full stack

RESULTADO

Una aplicación full stack funcional, con una demo pública independiente de los servicios privados de producción.

Ver demo (se abre en una pestaña nueva)GitHub (se abre en una pestaña nueva)

El problema

Organizar el contenido de una campaña y controlar qué información puede consultar cada usuario, manteniendo la privacidad de las wikis.

Qué hice

Diseñé la estructura y desarrollé frontend y backend: autenticación, modelo de datos, permisos, contenido, recursos multimedia y despliegue.

Qué aprendí

Pensar más allá de cada pantalla: modelar datos, controlar permisos desde servidor y mantener coherencia entre frontend, backend y base de datos.

Decisiones y detalles del desarrollo

Privacidad desde el servidor

Autenticación, usuarios y permisos para controlar el acceso al contenido de cada campaña.

Un modelo conectado

Base de datos, API y frontend coordinados para gestionar contenido y recursos multimedia.

Una demo independiente

Demo pública estática para enseñar el producto sin exponer los servicios privados de producción.

CrowdCompass

Orientación y gestión digital para eventos multitudinarios.

Proyecto ABP en equipo en la Universidad de Alicante para facilitar la orientación en grandes recintos mediante entradas, rutas interiores y representación 3D.

MI PAPEL

Desarrollo full stack y organización de equipo

RESULTADO

Aplicación completa desarrollada como proyecto ABP y desplegada públicamente.

El problema

Facilitar que los asistentes puedan consultar sus entradas, encontrar su asiento y orientarse dentro de un gran recinto.

Qué hice

Participé en la conexión entre frontend y backend, las herramientas de gestión y la visualización del recinto, además del reparto de tareas y las decisiones técnicas del equipo.

Qué aprendí

Organizar trabajo, tomar decisiones conjuntamente, integrar partes desarrolladas por distintas personas y adaptar la planificación cuando aparecían problemas.

Decisiones y detalles del desarrollo

Gestionar el evento

Usuarios, eventos, entradas con códigos QR y paneles de administración.

Orientar en el recinto

Recintos, zonas, asientos, rutas interiores y visualización 3D.

Construir en equipo

Reuniones de organización, integración de funcionalidades y planificación compartida.

También trabajamos publicación, SEO y redes sociales: mi primer contacto con la visibilidad y comunicación de un producto web.
