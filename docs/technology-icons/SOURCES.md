# Fuentes de los iconos

Los SVG de tecnologías proceden de [Simple Icons](https://github.com/simple-icons/simple-icons), licencia CC0 incluida en este directorio. Se generan localmente mediante `node scripts/technology-icons.mjs`; no se carga la biblioteca completa en el navegador.

El logo de Open Food Facts procede de su [repositorio oficial de diseño](https://github.com/openfoodfacts/openfoodfacts-design/blob/main/images/logos/openfoodfacts/off-logo-icon-light.svg).

Las categorías genéricas APIs, REST APIs, Web Augmentation y OAuth utilizan pictogramas de Phosphor, ya incluido en el proyecto. No se presentan como marcas con un logo oficial.
