## Perfil profesional

Soy un desarrollador con formación multimedia y enfoque full-stack. Me interesa crear productos donde la parte técnica y la experiencia de usuario estén bien conectadas: arquitectura clara, buen rendimiento, diseño visual coherente y flujos sencillos para quien usa la aplicación.

Trabajo especialmente cómodo en proyectos que combinan:

- Aplicaciones web con frontend moderno.
- APIs y backend estructurado.
- Bases de datos relacionales y modelado de datos.
- Diseño de interfaces, prototipado y experiencia de usuario.
- Automatización de procesos y herramientas internas.
- Proyectos creativos, narrativos o multimedia.

## Proyectos destacados

### WikiCodex

Aplicación web para organizar campañas, personajes, objetos, lugares, poderes, hechizos y contenido narrativo de partidas de rol.

- Frontend en React con una interfaz completa y responsive.
- Backend con Node.js, Express, Prisma y PostgreSQL.
- Gestión de privacidad, permisos, campañas, versiones y contenido multimedia.
- Demo estática pública preparada para GitHub Pages.
