## Professional Profile

I am a Multimedia Engineer graduated from the University of Alicante, specialised in software development and web technologies. My profile is mainly oriented towards frontend development, the area I enjoy the most and where I have developed a large part of my projects using technologies such as React, Angular, JavaScript, TypeScript, HTML and CSS.

At the same time, I have experience in fullstack development, working with technologies such as Node.js, Express, PostgreSQL, MySQL, Prisma and REST APIs. This allows me to work comfortably across the complete development of web applications, from user interfaces to server logic and database management.

During my studies and personal projects, I have participated in the development of applications focused on solving real problems, including management platforms, interactive tools and web applications with authentication, databases and online deployment.

I am currently continuing to expand my knowledge and develop projects focused on web applications, interactive software and modern development technologies.

## Featured Projects

### Mappleo

<p align="center">
  <a href="https://github.com/adrianvilellapro/Mappleo_App">
    <img src="./public/portfolio-assets/mappleo-logo.png" alt="Mappleo logo" width="130" />
  </a>
</p>

Web and Windows application for organising a job search, connecting companies, job offers, applications, contacts and networking events. Mappleo brings process tracking, tasks and important dates together in a visual workspace, with a Kanban board, calendar and statistics to make the next step clear.

<p align="center">
  <a href="https://adrianvilellapro.github.io/Mappleo_App/en/index.html">
    <img src="./public/portfolio-assets/mappleo-dashboard.png" alt="Mappleo dashboard showing the fictional John Miller profile; screenshot in Spanish" width="820" />
  </a>
</p>

<p align="center">
  <a href="https://github.com/adrianvilellapro/Mappleo_App"><img src="https://img.shields.io/badge/Repository-1f2937?style=for-the-badge&logo=github&logoColor=white" alt="Mappleo repository" /></a>
  <a href="https://adrianvilellapro.github.io/Mappleo_App/en/index.html"><img src="https://img.shields.io/badge/Demo-2563eb?style=for-the-badge&logo=githubpages&logoColor=white" alt="Mappleo web demo in English" /></a>
  <a href="https://github.com/adrianvilellapro/Mappleo_App/releases/latest"><img src="https://img.shields.io/badge/Windows-Download_installer-0f766e?style=for-the-badge" alt="Download Mappleo for Windows" /></a>
</p>

- Responsive web app built with React, Next.js and TypeScript; backend with Prisma and PostgreSQL.
- Windows application with Electron, encrypted local SQLite storage, offline use and optional synchronisation with a web account. CVs and cover letters stay exclusively on the computer.
- Kanban with draggable cards, application history, calendar, statistics and data exports.
- Authentication, personal-field encryption and automated tests with Vitest and Playwright. Docker for local development and CI with GitHub Actions.
- Interactive static web demo with fictional data, no registration and no production service usage.

### Nutrivisor

<p align="center">
  <a href="https://github.com/adrianvilellapro/Nutrivisor">
    <img src="./public/portfolio-assets/nutrivisor-logo.png" alt="Nutrivisor logo" width="150" />
  </a>
</p>

Academic augmented-web project applied to online grocery shopping. Nutrivisor enriches the shopping experience with extended nutritional information, visual indicators and automatic filters over Mercadona products, combining data from the website itself with information from Open Food Facts.

<p align="center">
  <a href="https://github.com/adrianvilellapro/Nutrivisor">
    <img src="./public/portfolio-assets/nutrivisor-captura.png" alt="Nutrivisor screenshot" width="820" />
  </a>
</p>

<p align="center">
  <a href="https://github.com/adrianvilellapro/Nutrivisor"><img src="https://img.shields.io/badge/Repository-1f2937?style=for-the-badge&logo=github&logoColor=white" alt="Nutrivisor repository" /></a>
  <a href="https://chromewebstore.google.com/detail/niobahhmkhhjpdafnnmcdfpkbkjipiie?utm_source=item-share-cb"><img src="https://img.shields.io/badge/Chrome_Web_Store-2563eb?style=for-the-badge&logo=googlechrome&logoColor=white" alt="Nutrivisor on Chrome Web Store" /></a>
</p>

- Functional Tampermonkey userscript for `tienda.mercadona.es`.
- Evolution towards a Chrome extension using Manifest V3 and Vite.
- Nutritional data lookup, Nutri-Score, NOVA, allergens, additives and composition.
- Automatic visual filters to support faster and more informed purchase decisions.
